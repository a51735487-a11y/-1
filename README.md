# Звёздный ловец

Космическая мини-игра на HTML, CSS и JavaScript без библиотек. Лови падающие звёзды кораблём: одна звезда даёт одно очко, три пропуска заканчивают раунд. Каждые пять очков скорость растёт. Рекорд сохраняется в браузере, если локальное хранилище доступно.

## Запуск

Из корня проекта:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Открыть в браузере адрес `http://127.0.0.1:8000`. Это адрес локального сервера на машине, где запущена команда. Для облачной среды использовать доступное перенаправление порта 8000. ES modules требуют HTTP-сервер; открытие файла через `file://` не поддерживается.

Управление: стрелки влево/вправо, мышь или касание игрового поля. При скрытии вкладки игра приостанавливается.

## Проверка

Нужен Node.js 24 или новее:

```bash
node --test tests/*.test.mjs
git diff --check
```

Браузерная проверка: начать игру, поймать звезду, пропустить три, повторить раунд, проверить рекорд после перезагрузки. Проверить управление на компьютере и телефоне и отсутствие ошибок в консоли.
