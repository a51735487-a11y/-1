# «Поймай звезду» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Создать мини-игру для развлечения с ловлей звёзд, тремя жизнями и рекордом.

**Architecture:** Независимый модуль игровой логики и браузерный контроллер с Canvas. HTML и CSS обеспечивают адаптивный русский интерфейс; рекорд сохраняется локально.

**Tech Stack:** HTML, CSS, JavaScript ES modules, Canvas, localStorage; Node.js 24 со встроенным тестовым раннером, имеющийся Chromium и Python для проверки.

**Spec:** `docs/superpowers/specs/2026-10-12-catch-stars-design.md`

## Global Constraints

- Без фреймворков и сторонних библиотек; без установки зависимостей приложения.
- Комментарии и интерфейс на русском, небольшие функции; `assets` и PDF не изменять.
- Космический интерфейс «Звёздный ловец»: тёмно-синий фон, звёздное небо и планета, голубое и фиолетовое свечение, корабль вместо корзины; изображения только CSS и Canvas. При prefers-reduced-motion отключить декоративную анимацию.
- Поле 480 × 640; появление звёзд каждые 900 мс.
- Скорость падения 150, +20 каждые пять очков, максимум 350; движение корзины 420 единиц/с.
- Три жизни, одно очко за звезду; при нуле жизней немедленное завершение.
- Управление мышью, стрелками и касанием; пауза в скрытой вкладке.
- `catch-stars-best` хранит неотрицательный целочисленный рекорд; сбой хранилища не мешает игре.

## Review Focus

1. Быстрая звезда за один кадр пересекает корзину: засчитать попадание, а не пропуск.
2. Несколько пропусков в одном кадре: жизни не уходят ниже нуля, события после завершения не начисляют очки.
3. Уход фокуса при зажатой стрелке: корзина не продолжает движение самостоятельно.
4. Некорректное или недоступное хранилище: игра запускается, рекорд остаётся корректным.
5. Повторные запуски и смена размера поля: нет дублирования циклов, указатель остаётся согласован с корзиной.

### Task 1: Проверяемая игровая логика

**Interfaces:** Экспортировать `createGame() -> State`, `startGame(state) -> void`, `moveBasket(state, x) -> void`, `getFallSpeed(score) -> number`, `stepGame(state, dtSeconds, direction = 0, random = Math.random) -> void`. State: `{status: 'idle'|'running'|'over', score, lives, basket: {x,y,width,height}, stars: [{x,y,radius}], spawnElapsed}`. Координаты корзины означают верхний левый угол; звезды — центр. Корзина 88 × 24, y=588; радиус звезды 12. `moveBasket` принимает желаемую координату центра. Время dt неотрицательно; браузер ограничивает его до 0.05 секунды.
