# Звёздный ловец

Браузерная мини-игра для развлечения: корабль ловит падающие звёзды, получает очки и теряет жизнь при пропуске. После трёх пропусков раунд заканчивается; рекорд сохраняется в браузере.

## Стек

HTML, CSS и JavaScript (ES modules), Canvas и `localStorage`. Без фреймворков и сторонних библиотек. Проверки логики — встроенный тестовый раннер Node.js.

## Правила работы

- Комментарии в коде писать по-русски.
- Не подключать фреймворки и сторонние библиотеки.
- Папку `assets` и её содержимое не изменять, не удалять и не перемещать.
- Длинные функции разбивать на небольшие функции с понятными именами и одной задачей.
- После изменений запустить `node --test tests/*.test.mjs` и `git diff --check`.
- Открыть приложение в браузере через локальный HTTP-сервер и проверить отсутствие ошибок в консоли.
- Проверить начало раунда, ловлю звезды и обновление счёта, потерю жизни при пропуске, завершение после трёх пропусков и повторный запуск.
- Проверить стрелки, мышь и касание, отображение на телефоне, паузу в скрытой вкладке и сохранение рекорда после перезагрузки.
- Если проверку выполнить нельзя, указать причину в описании PR; не заявлять, что она пройдена.

## Команды для PR

Выполнять из корня репозитория. Добавлять только файлы своей задачи, без `assets` и существующего PDF. Название ветки и описание менять под конкретные изменения.

```bash
git switch -c feat/star-catcher
node --test tests/*.test.mjs
python -m http.server 8000 --bind 127.0.0.1
# Проверить игру в браузере, затем остановить сервер сочетанием Ctrl+C.
git status --short
git diff --check
git diff
git add index.html styles.css app.js game-logic.js AGENTS.md tests
git diff --cached
git commit -m "feat: создать космическую мини-игру"
git push -u origin HEAD
gh pr create --base main --title "Космическая мини-игра Звёздный ловец" --body-file /tmp/star-catcher-pr.md
```

Перед `gh pr create` подготовить `/tmp/star-catcher-pr.md` с описанием изменений и фактическими результатами проверок. Команды push и создания PR выполнять только по просьбе пользователя.
